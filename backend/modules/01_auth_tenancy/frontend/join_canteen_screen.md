# Screen: Join Canteen (Invite Code)

## 1. Description
Allows managers or staff members to join an existing canteen by entering a 6-digit invite code generated by the owner/manager.

* **Dart File**: [join_canteen_screen.dart](file:///Users/daviditc/Documents/personal_projects/smart-hisab/mobile/lib/features/auth/join_canteen_screen.dart)
* **Riverpod Provider**: `authNotifierProvider`

---

## 2. User Actions
| Action Name | Trigger | Intended Outcome |
| :--- | :--- | :--- |
| **Redeem Invite Code** | Tap "Join Canteen" button | Calls `join_tenant_by_code` RPC, assigns role, sets active canteen. |

---

## 3. APIs Used

### Mutation RPC: `join_tenant_by_code`
* **Method**: `supabase.rpc('join_tenant_by_code', params: {...})`
* **Input Payload**:
```json
{
  "p_code": "AB89X2"
}
```
* **Output Response**:
```json
{
  "success": true,
  "tenant_id": "e2a3b4c5-0000-0000-0000-000000000001",
  "tenant_name": "Dhaka Central Canteen",
  "role": "manager"
}
```
* **Target Local Cache Mutation**:
  * Adds tenant to user's memberships list in local state.
  * Sets active tenant ID in Hive storage.
  * Routes user into `HomeScreen`.
